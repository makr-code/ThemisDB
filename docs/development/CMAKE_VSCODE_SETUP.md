# CMake VSCode Setup

This document describes how to set up CMake with Visual Studio Code for efficient development workflows.

## Prerequisites

- Ensure you have CMake installed on your system.
- Install the CMake and CMake Tools extensions from the VSCode marketplace.

## Setup Steps

1. Open your project folder in VSCode.
2. Open the command palette (F1) and type `CMake: Configure`. Follow the prompts to configure your project.
3. After configuration, you can build your project using `CMake: Build`.

For more detailed information on specific configurations, refer to the official CMake documentation.
