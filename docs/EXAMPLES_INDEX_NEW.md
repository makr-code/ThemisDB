## 🛠 Example Structure

Each example includes:
- `README.md` - Overview and instructions
- `HOW_TO.md` - Step-by-step guide (most examples)
- `ARCHITECTURE.md` - Design details (some examples)
- Source code - Complete working implementation
- Sample data - Test datasets
- Configuration - Setup files

## 🚀 Running Examples

### Using Docker
```bash
cd examples/XX_example_name
docker-compose up -d
```

### From Source
```bash
cd examples/XX_example_name
# Follow README.md instructions
```

### Prerequisites
- ThemisDB installed and running
- Language runtimes (Python, Node.js, etc.)
- Dependencies (see individual READMEs)
