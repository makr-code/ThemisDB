# ThemisDB v1.1.0 Release Notes

**Release Date:** Q1 2026  
**Version:** 1.1.0  
**Focus:** Optimization Release - Better Library Utilization + vLLM Co-Location

## Summary

v1.1.0 delivers **3-10x performance improvement** by better utilizing existing libraries rather than adding new dependencies. Only **1 new dependency** (mimalloc) added.

**Key Features:**
- 🚀 RocksDB: TTL, Incremental Backup, Statistics Export
- 🚀 TBB: Parallel Sort (2-4x), Concurrent Hash Maps (2-3x)
- 🚀 Arrow: Parquet Export (90% compression)
- 🚀 CUDA: Low-priority streams for vLLM
- 🚀 vLLM: Resource manager for AI/ML workloads
- 🚀 mimalloc: 20-40% memory boost

## What's Implemented

All features from [VARIANT_STRATEGY_v1.1.0.md](../analysis/VARIANT_STRATEGY_v1.1.0.md) are now complete.

See full documentation and examples in the main README and analysis docs.

## Build Variants

- **Standard (OLTP):** 16 dependencies
- **OLAP:** 17 dependencies  
- **Embedded:** 12 dependencies
- **vLLM Co-Location:** 16 dependencies + CUDA

## Quick Start

```bash
# Standard build with mimalloc
cmake -DTHEMIS_USE_MIMALLOC=ON ..
make

# vLLM co-location
cmake -DTHEMIS_VLLM_COLOCATION=ON ..
make

# Docker deployment
docker-compose -f docker-compose-vllm.yml up -d
```

## Breaking Changes

None! Fully backward compatible with v1.0.x.
