# Version Badge

[![Version](https://img.shields.io/badge/version-1.8.1--rc2-blue)](https://github.com/makr-code/ThemisDB/releases)

## What it shows

The current version of ThemisDB according to the [`VERSION`](../../../VERSION) file tracked in the repository. Pre-release suffixes such as `-rc2` indicate a release candidate.

## What it does NOT guarantee

- The badge reflects the version string in the repository, not necessarily a published or tested release artifact.
- A pre-release version such as `-rc2` is a release candidate, not a final GA release.

## Source of truth

| Source | URL |
|--------|-----|
| Version file | [`VERSION`](../../../VERSION) in the repository root |
| Published releases | <https://github.com/makr-code/ThemisDB/releases> |
| Release notes | [`CHANGELOG.md`](../../../CHANGELOG.md) |

## How contributors can verify

```bash
cat VERSION
```

The GitHub Releases page is the authoritative record of tagged, validated releases.
