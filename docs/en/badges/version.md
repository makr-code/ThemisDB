# Version Badge

[![Version](https://img.shields.io/badge/version-1.5.0--dev-blue)](https://github.com/makr-code/ThemisDB/releases)

## What it shows

The current version of ThemisDB according to the [`VERSION`](../../../VERSION) file tracked in the repository. A `-dev` suffix indicates an in-progress development cycle between official releases.

## What it does NOT guarantee

- The badge reflects the version string in the repository, not necessarily a published or tested release artifact.
- A `-dev` version has **not** passed the full release validation process.

## Source of truth

| Source | URL |
|--------|-----|
| Version file | [`VERSION`](../../../VERSION) in the repository root |
| Published releases | <https://github.com/makr-code/ThemisDB/releases> |
| Release notes | [`CHANGELOG.md`](../../../CHANGELOG.md) |

## How contributors can verify

```bash
cat VERSION
```

The GitHub Releases page is the authoritative record of tagged, validated releases.
