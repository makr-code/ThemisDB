# GitHub Stars Badge

[![Stars](https://img.shields.io/github/stars/makr-code/ThemisDB?style=flat)](https://github.com/makr-code/ThemisDB/stargazers)

## What it shows

The total number of GitHub stars ThemisDB has received. Stars are a widely-used community signal of interest and appreciation for an open-source project.

## What it does NOT guarantee

- Star count reflects interest, not production deployments or code quality.
- The badge is served by shields.io and may be cached for a short period.
