# GitHub Forks Badge

[![Forks](https://img.shields.io/github/forks/makr-code/ThemisDB?style=flat)](https://github.com/makr-code/ThemisDB/forks)

## What it shows

The total number of times ThemisDB has been forked on GitHub. Forks are an indicator of active community engagement and downstream usage or contributions.

## What it does NOT guarantee

- The fork count includes all forks, including inactive or experimental ones.
- The badge is served by shields.io and may be cached for a short period.

## Source of truth

| Source | URL |
|--------|-----|
| GitHub Forks page | <https://github.com/makr-code/ThemisDB/forks> |

## How contributors can verify

Visit the [ThemisDB repository](https://github.com/makr-code/ThemisDB) on GitHub. The fork count is shown next to the **Fork** button in the repository header.
