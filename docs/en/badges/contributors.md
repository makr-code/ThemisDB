# Contributors Badge

[![Contributors](https://img.shields.io/github/contributors/makr-code/ThemisDB)](https://github.com/makr-code/ThemisDB/graphs/contributors)

## What it shows

The total number of unique contributors who have committed code to the ThemisDB repository. This reflects the breadth of community involvement in the project.

## What it does NOT guarantee

- The count is based on commit authors as recognised by GitHub. Contributions via issue reports, reviews, or discussions are not reflected.
- Bots and automated commits (e.g., from GitHub Actions) may be included in the count.
