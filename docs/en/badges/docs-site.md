# Docs Site Badge

[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://makr-code.github.io/ThemisDB/)

## What it shows

A static badge confirming that the ThemisDB documentation is published and available on **GitHub Pages**. Clicking the badge opens the full documentation site.

## What it does NOT guarantee

- The badge is static and always shows "GitHub Pages". It does not reflect the live build status of the docs deployment.
- Individual pages may be incomplete or out-of-date with the source; refer to the `develop` branch for the latest content.

## Source of truth

| Source | URL |
|--------|-----|
| Documentation site | <https://makr-code.github.io/ThemisDB/> |
| MkDocs configuration | [`mkdocs.yml`](../../../mkdocs.yml) in the repository root |

## How contributors can verify

Navigate to [https://makr-code.github.io/ThemisDB/](https://makr-code.github.io/ThemisDB/) to browse the live documentation.
