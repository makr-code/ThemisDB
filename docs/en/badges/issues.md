# Open Issues Badge

[![Open Issues](https://img.shields.io/github/issues/makr-code/ThemisDB)](https://github.com/makr-code/ThemisDB/issues)

## What it shows

The number of currently open issues in the ThemisDB repository. This is a transparency indicator for potential contributors and users, showing how many reported bugs, feature requests, or questions are awaiting resolution.

## What it does NOT guarantee

- The count includes all open issues regardless of label (bugs, enhancements, questions, etc.).
- A high issue count can reflect active community engagement as much as outstanding problems.
