# PRs Welcome Badge

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen)](CONTRIBUTING.md)

## What it shows

A static badge indicating that ThemisDB actively welcomes pull requests from the community. This is a common open-source signal that the maintainers are receptive to external contributions.

## What it does NOT guarantee

- Submission of a PR does not guarantee acceptance. All contributions are reviewed against the project's quality, scope, and roadmap criteria.
