## Termes

- **AQL** : Langage de requête de ThemisDB (similaire au format JSON)
- **Entity** : Élément de nœud (document) dans le modèle graphe/document
- **Edge** : Relation entre les entités
- **MVCC** : Multi-Version Concurrency Control (contrôle de concurrence multi-version)
- **WAL** : Write-Ahead Log de RocksDB (journal d'écriture anticipée)
- **TSStore** : Composant de stockage de séries temporelles de ThemisDB
- **HNSW** : Algorithme basé sur les graphes pour la recherche de plus proches voisins de vecteurs
- **DCP** : Données à Caractère Personnel (informations permettant d'identifier une personne)
- **OpenAPI** : Spécification des API HTTP REST
