## Overview

The `llm_wiki` module provides persistent knowledge storage and capability management for wiki-like LLM data: workspace state, process policies, and repository-aware knowledge records used by AI workflows.

## Primary sources

- `src/llm_wiki/` — implementation of wiki-state persistence and policy handling
- `include/llm_wiki/` — public interfaces for plugin and status contracts
- `src/llm_wiki/ARCHITECTURE.md` — architectural organization
- `src/llm_wiki/FUTURE_ENHANCEMENTS.md` — planned evolution and feature work

## Key responsibilities

- persistent knowledge and status records
- policy-driven processing and validation
- state management for AI documentation and retrieval workflows
- integration with broader LLM and wiki-based knowledge infrastructure
