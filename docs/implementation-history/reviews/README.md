# Review History

Dieses Verzeichnis enthaelt historische Review-Berichte und deren Auswertungen aus dem docs-Root.

## Zweck
- Root-Aufraeumung fuer bessere Navigation.
- Nachvollziehbarkeit von abgeschlossenen Review-Runden.

## Ablage-Regel
- Snapshot-Dokumente wie `*_REVIEW*.md`, `*CODE_REVIEW*.md` und finale Review-Reports werden hier abgelegt,
  sofern sie nicht als dauerhafte Prozessdokumentation genutzt werden.
