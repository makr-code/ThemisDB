# TCO Calculator - Total Cost of Ownership Tool

## Overview

Web-based calculator for estimating the total cost of ownership (TCO) for ThemisDB deployments. Available as a standalone web application or WordPress plugin.

## Use Cases

- Compare cloud vs. on-premises costs
- Plan deployment budgets
- Justify infrastructure investments
- Compare ThemisDB to alternatives
- Generate cost estimates for proposals

## Features

- **Infrastructure Costs:** Servers, storage, network
- **Personnel Costs:** Admin, DevOps, support staff
- **License Costs:** Operating systems, tools
- **Operational Costs:** Power, cooling, facilities
- **AI/LLM Costs:** GPU, model hosting, inference
- **Interactive Visualizations:** Charts with Chart.js
- **Export Options:** PDF, CSV, JSON
