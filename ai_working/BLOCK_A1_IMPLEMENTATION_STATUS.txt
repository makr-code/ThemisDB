PRODUCTION-GRADE PATTERNS APPLIED
==================================

1. Lock-Free Atomics
   - Config parameters: std::atomic<double>, std::atomic<size_t>
   - Memory ordering: acquire-release for synchronization, relaxed for counters
   - No sequential consistency overhead

2. Bounded Concurrency Control
   - Atomic reference counters track in-flight operations
   - Backpressure via yield() when limit exceeded
   - RAII scope guards ensure counter decrements on scope exit

3. LRU Cache Eviction
   - Capacity-based eviction triggered at 90% threshold
   - Target 50% after eviction to provide breathing room
   - Reference counting prevents use-after-free

4. Reader-Writer Lock Fairness
   - std::shared_mutex with consistent lock ordering
   - Prevents reader starvation under writer bursts

5. Deterministic RNG for shouldDecompose()
   - Per-embedding seeding with xorshift64
   - No collisions across threads for same embedding
