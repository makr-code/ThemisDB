HOW PHASE 11 IMPLEMENTS PROGRESSIVE CONTEXT:
┌────────────────────────────────────────────────────────────────────────────┐
│                                                                              │
│  Phase 11 uses standardized ±5 line context window across all scanners:    │
│                                                                              │
│  Example: Sensitive Logging Detection (data_leak.py)                       │
│  ──────────────────────────────────────────────────                        │
│                                                                              │
│  Pattern: Require BOTH log function + sensitive argument in same context    │
│                                                                              │
│    Line 42:  logger.log(password);     ← FLAGGED                           │
│              ^       ^     ^                                                │
│              │       │     └─ Sensitive arg                                │
│              │       └─ Log function                                        │
│              └─ Within ±5 lines = gap detected                              │
│                                                                              │
│    Line 50:  password = get_secret();                                      │
│    Line 51:  logger.info("Processing...");                                 │
│    Line 52:  do_work(password);       ← NOT flagged (gap too far)          │
│              ^         ^                                                    │
│              │         └─ Sensitive arg 5+ lines away from log              │
│              └─ Log function separate                                       │
│                                                                              │
