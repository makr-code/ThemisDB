DELIVERABLE 5: DETERMINISTIC CONFLICT RESOLUTION (LWW)
================================================================================

Requirement: Implement Last-Write-Wins with monotonic version clocks, no silent
failures, explicit conflict reporting, and deterministic outcome guarantees.

Implementation:
✓ Monotonic Version Clocks
  - ProcessModelManager::operation_counter_ (atomic counter)
  - ProcessLinker::link_operation_counter_ (atomic counter)
  - ProcessModelRecord::revision (monotonically incremented)
  - Each operation assigned unique sequence number

✓ Last-Write-Wins Conflict Resolution
  - ProcessModelManager::detectConflict_() compares revisions
  - Higher revision always wins
  - TransactionGuard fails if conflict detected
  - Application retries with fresh version

✓ No Silent Failures
  - Conflicts explicitly reported via TransactionGuard destruction
  - CONCURRENCY_INCIDENT raised for conflict detection
  - Full audit trail of all writes
  - No automatic recovery without explicit retry

✓ Explicit Conflict Reporting
  - TransactionGuard::markFailed() signals conflict
  - ~TransactionGuard() calls rollbackTransaction_()
  - rollbackTransaction_() logs conflict with details
  - Application can catch and handle conflicts

✓ Deterministic Outcome Guarantees
  - Revision ordering is total: a.revision < b.revision XOR a.revision > b.revision
  - No ties: Impossible to have same revision after update
  - Idempotent: Reapplying same operation is safe
  - Consistent: Same conflict always resolved same way

Conflict Resolution Strategy:
1. Operation begins: createTransaction_() captures starting revision
2. Operation proceeds: Modifications applied in memory
3. Before commit: detectConflict_() checks if revision changed
4. On conflict: TransactionGuard::markFailed() sets flag
5. On destruction: Destructor calls rollbackTransaction_()
6. Rollback: Restores from versioned snapshot
7. Reporting: SPDLOG messages with operation details

Files Modified/Created:
- include/process/process_determinism_spec.h (contract frozen)
- src/process/process_model_manager.cpp (LWW implementation)
- src/process/process_linker.cpp (conflict tracking)

Determinism Guarantees:
✓ Parsing: Deterministic UTF-8 validation, format parsing
✓ Serialization: Deterministic output from static methods
✓ Conflict resolution: Deterministic LWW via revision comparison
✓ No non-determinism: No timestamps in output, only metadata
