================================================================================
GAP OUTPUT FORMAT
================================================================================

Each detected gap includes:
  - file:         Relative path from repo root
  - line:         Line number of detection
  - type:         Gap type (toctou_race, double_checked_locking, lost_wakeup)
  - severity:     HIGH or CRITICAL
  - snippet:      Source code snippet (≤100 chars)
  - description:  Human-readable description (CWE-362 referenced)
  - remediation:  Specific, actionable fix recommendation

Example:
  {
    "file": "src/module/worker.cpp",
    "line": 156,
    "type": "lost_wakeup",
    "severity": "CRITICAL",
    "snippet": "cv.wait();  // ERROR: No lock parameter",
    "description": "Lost wakeup: condition variable without proper lock",
    "remediation": "Use: std::unique_lock<std::mutex> lock(m); cv.wait(lock, predicate);"
  }
