## 🗂️ Dokumentationsrichtlinien

### Aktuelle Dokumentation
- **Status: ✅ Aktuell** - Wird aktiv gepflegt und ist auf dem neuesten Stand
- Diese Dokumente sind die primären Referenzen für das Projekt

### Archivierte Dokumentation
- **Status: ⚠️ Archiviert** - Historisch wertvoll, aber nicht mehr aktuell
- Session-Berichte und Phase-Completion-Dokumente dienen als Entwicklungshistorie
- Bei Bedarf in `docs/archive/` zu finden

### Dokumentation aktualisieren
1. Änderungen im Root-Projekt-Markdown dokumentieren: `../README.md`, `../EVENTS.md`, `../MEDIATR_ARCHITECTURE_AUDIT.md`
2. Technische Details in entsprechende `docs/`-Dateien einfügen
3. Bei größeren Features neue Dokumente in entsprechende Kategorie einfügen
4. Diesen Index aktualisieren
