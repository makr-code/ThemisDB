================================================================================
REGEX PATTERNS USED
================================================================================

Iterator Detection:
  - Capture: (?:auto|.*?)\s+\w+\s*=\s*\w+\.(?:begin|rbegin|cbegin)
  - Modify: \.(push_back|pop_back|insert|erase|clear|resize|reserve)\s*\(
  - Use: \*iterator_name | iterator_name\-> | \*\*iterator_name

Move Detection:
  - Pattern: (\w+)\s*=\s*std::move\s*\(\s*(\w+)\s*\)
  - Reuse: moved_from\.|\w+->\|&moved_from\b|\[moved_from\]

Delete Detection:
  - Pattern: delete\s+(\w+)
  - Try/Catch: try\s*\{ ... \}\s*catch

================================================================================
KNOWN LIMITATIONS
================================================================================

1. Regex-based detection (not full C++ AST)
   → May have false positives in complex templates
   → Macro expansions not analyzed

2. Brace-counting scope analysis
   → Cannot distinguish all scope boundaries
   → Lambda captures not tracked

3. Pattern-specific detection
   → Only detects specified patterns
   → Subtle variations may be missed
