## Legend

| Column | Meaning |
|---|---|
| **File** | Path relative to `src/` |
| **Activation** | Build flag / runtime condition that enables the stub |
| **Production Delta** | How behaviour differs from the real implementation |
| **Funktions-Impact** | Auswirkung des Stubs auf die ThemisDB-Funktionalität (siehe Skala unten) |
| **Roadmap Ref** | ROADMAP / FUTURE_ENHANCEMENTS section that tracks the real impl |
| **Target** | Planned version for removal / replacement |

### Funktions-Impact-Skala

| Symbol | Stufe | Bedeutung |
|---|---|---|
| 🔴 **Kritisch** | Kernsystem beeinträchtigt | Datenverlust, Sicherheitslücke oder vollständiger Funktionsausfall eines zentralen Features (z. B. Verschlüsselung, Replikation, Transaktionen) |
| 🟠 **Hoch** | Wichtiges Feature fehlt | Wesentliche Funktion nicht verfügbar oder starke Qualitätseinbußen; Fallback vorhanden, aber unzureichend für Produktion |
| 🟡 **Mittel** | Spürbare Einschränkung | Funktion teilweise degradiert; Fallback funktioniert, aber mit messbarem Qualitäts- oder Leistungsverlust |
| 🟢 **Niedrig** | Geringer Unterschied | Geringfügiger Performance- oder Qualitätsunterschied; alle kritischen Pfade sind funktionsfähig |
| ⚪ **Minimal** | Test-Gate / by design | Nur aktiv in Test-Builds oder als permanenter Fallback; kein Einfluss auf Produktionspfade |
| — | Aufgelöst | Stub wurde entfernt und durch Produktionsimplementierung ersetzt (Strikethrough-Zeilen) |
