BENCHMARK MODES
================================================================================

Mode: COMPLETE SUITE (Full)
  Command: --mode full --databases DB1 DB2 --output-dir results
  Tests: YCSB + TPC-C + TPC-H + Sysbench
  Duration: 10-15 minutes
  Output: Console + 5 JSON files

Mode: YCSB
  Command: --mode ycsb --workloads A B C
  Tests: 6 Cloud/NoSQL workloads
  Reference: 1,000 - 100,000 ops/sec (workload-dependent)
  Grades: A-F based on throughput ratio

Mode: TPC-C (OLTP)
  Command: --mode tpcc --scale medium
  Tests: 5 Transaction types (New Order, Payment, etc.)
  Reference: 1,000 - 100,000 TPMC (scale-dependent)
  SLA: P95 < 10ms

Mode: TPC-H (OLAP)
  Command: --mode tpch --scale-factor 1
  Tests: 22 Complex SQL Queries
  Reference: 20,000 - 200 QPhH (scale-dependent)
  Metrics: Query time distribution

Mode: Sysbench
  Command: --mode sysbench
  Tests: 5 OLTP/Storage workloads
  Reference: 200 - 2,000 trans/sec (workload-dependent)
  Metrics: Latency distribution

Mode: Scientific
  Command: --mode scientific --database DB --repetitions 10
  Tests: Rigorous statistical benchmark
  Validates: Warmup, Repetitions, Hardware, Stats, Reproducibility
  Output: QA Report + Compliance Score

Mode: Standards (Alias for Full)
  Command: --mode standards --databases DB1 DB2
