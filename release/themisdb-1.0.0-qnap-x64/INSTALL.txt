ThemisDB v1.0.0 - QNAP NAS Edition (Ubuntu 20.04+, GLIBC 2.31+)
================================================================

Installation auf QNAP NAS:
1. Container Station installieren
2. Docker Compose verwenden (empfohlen):
   docker-compose -f docker-compose.qnap.yml up -d

Oder Docker Image verwenden:
   docker pull themisdb/themisdb:qnap
   docker run -p 18765:18765 -v /share/themisdb:/data themisdb/themisdb:qnap

Native Installation (fortgeschritten):
1. Binary nach /opt/themisdb/ kopieren
2. chmod +x themis_server
3. ./themis_server starten

Systemanforderungen:
- QNAP NAS mit x64 CPU
- Container Station oder Linux Station
- GLIBC 2.31+ (QTS 5.0+)
- 2 GB RAM minimum, 4+ GB empfohlen

Konfiguration:
- Port: 18765
- Daten-Verzeichnis: /data (Docker) oder /share/themisdb (nativ)
