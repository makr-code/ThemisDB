## Installation Guide

### From Complete Package (Recommended)
1. Extract the ZIP package
2. Review `README.md` in package root
3. Copy `config/config.json` to your deployment location
4. Customize configuration as needed
5. Run the binary with `--config` flag

### From Minimal Package
1. Extract ZIP
2. Obtain configuration (from separate source or generate)
3. Run binary with `--config` flag

### DEB/RPM Packages
1. Install: `sudo dpkg -i themisdb_1.0.1_amd64.deb` or `sudo rpm -i themisdb-1.0.1-1.x86_64.rpm`
2. Configuration typically installed to `/etc/themis/`
3. Service typically auto-configured via systemd
