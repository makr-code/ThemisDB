## Installation Instructions by Package Type

### Minimal Installation
```bash
# Extract
unzip themis-1.0.1-windows-x64.zip

# Use binary directly
./themis_server --config /path/to/config.json
```

### Complete Installation
```bash
# Extract
unzip themisdb-1.0.1-linux-x64-complete.zip
cd themis-1.0.1-complete

# Review docs first
cat README.md
cat INSTALLATION.md

# Create directories manually
mkdir -p data logs cache plugins backups temp

# Run with config
./bin/themis_server
```

### Production Installation (RECOMMENDED)
```bash
# Extract
unzip themisdb-1.0.1-linux-x64-prod.zip
cd themis-1.0.1-prod

# (All directories already exist!)

# Make script executable
chmod +x scripts/start-themis.sh

# Start server
./scripts/start-themis.sh start

# Verify
curl http://localhost:8080/health

# View logs
tail -f logs/application.log
```

## Post-Installation Steps

### After Starting (all packages)

1. **Verify Server is Running**
   ```bash
   curl http://localhost:8080/health
   ```

2. **Check Version**
   ```bash
   curl http://localhost:8080/version
   ```

3. **View Metrics**
   ```bash
   curl http://localhost:8080/metrics
   ```

4. **Review Logs**
   ```bash
   tail -f logs/application.log
   ```

### Production-Specific Setup

5. **Customize Configuration** (production package only)
   ```bash
   # Edit the configuration file
   nano config.json
   
   # Reload configuration
   curl -X POST http://localhost:8080/config/reload
   ```

6. **Set Backup Strategy**
   ```bash
   # Use included backup script
   ./scripts/backup-incremental.sh
   ```

7. **Configure Monitoring** (optional)
   ```bash
   # Use included Jaeger integration
   ./scripts/run_server_with_jaeger.sh
   ```

## Troubleshooting by Package

### Minimal Package
- **Problem**: Binary won't start
  - **Solution**: Ensure config.json is in the working directory
  - **Solution**: Check permissions: `chmod +x themis_server`

### Complete Package
- **Problem**: Still unsure about setup
  - **Solution**: Read `INSTALLATION.md` in the package
  - **Solution**: Review examples in `examples/` directory

### Production Package
- **Problem**: Directories not created
  - **Solution**: Already included - just extract!
  
- **Problem**: Script won't run on Linux
  - **Solution**: Make executable: `chmod +x scripts/start-themis.sh`

- **Problem**: Server won't start
  - **Solution**: Run `scripts/start-themis.sh foreground` to see errors
