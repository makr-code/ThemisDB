# Private Hyperscaler Modules

Dieses Verzeichnis ist für private, owner-kontrollierte Submodule reserviert.

Erwartete private Module:

- `plugins/private/themisdb-hyperscaler-core`

Hinweise:

- Die Repositories sind absichtlich **nicht** öffentlich.
- Hyperscaler-Konfigurationen schlagen fehl, wenn diese Module nicht vorhanden sind.
- Signing/Signatur-Generierung erfolgt über das Submodul `plugins/themisdb_plugin_signer`.
