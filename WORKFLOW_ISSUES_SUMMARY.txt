[CRITICAL-1] ci-release.yml: Invalid Workflow Reference Syntax
─────────────────────────────────────────────────────────────
File:     .github/workflows/ci-release.yml
Line:     594
Problem:  Uses "uses:" syntax to call another workflow file
          (workflow files cannot be called this way)
Impact:   Release automation fails - changelog never updated
Severity: 🔴 CRITICAL - Affects production releases

Current Code:
  uses: ./.github/workflows/release-changelog.yml
  with:
    mode: update
    ...

Why It's Wrong:
  - "uses:" is for composite actions in .github/actions/
  - Workflow-to-workflow calls need "workflow_call:" trigger
  - Syntax is silently ignored by GitHub Actions

Solution:
  Add "workflow_call:" trigger to ci-release.yml's "on:" section

Estimated Fix Time: 10 minutes
Detailed Plan: See WORKFLOW_FIX_PLAN.md
