# Test Configuration Examples

This directory contains example YAML configurations for Phase 2 testing.

## Available Configurations

### test_speculative_decoding.yaml
Configuration for testing Speculative Decoding feature.

### test_continuous_batching.yaml
Configuration for testing Continuous Batching feature.

### test_combined_optimizations.yaml
Configuration for testing all Phase 1 + Phase 2 features together.

## Usage

These configurations are automatically generated by the test scripts or can be used as templates for manual testing.

```bash
# Use with ThemisDB
./themis-server --config scripts/test_phase2/configs/test_combined_optimizations.yaml
```
