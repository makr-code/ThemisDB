# ThemisDB Manuscript Artifact Checklist

**Status**: Active  
**Last Updated**: 2026-08-10  
**Scope**: Minimum evidence package before promoting a manuscript to submission-candidate state.

## Required Items

- [ ] manuscript header metadata complete
- [ ] novelty delta stated against closest 3-5 papers
- [ ] repository evidence table filled with concrete files and sections
- [ ] module-level status checked against canonical `src/<module>/ROADMAP.md` or `README.md`
- [ ] experiment protocol linked from `research/experiments/`
- [ ] raw benchmark / test artefacts identified
- [ ] claim boundaries documented
- [ ] overlap / predecessor / successor decision recorded
- [ ] venue fit stated explicitly
- [ ] reproducibility caveats documented
