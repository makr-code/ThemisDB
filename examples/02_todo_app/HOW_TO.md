# Todo-App - Bedienungsanleitung

## 🎯 Übersicht

Diese Anleitung zeigt Ihnen, wie Sie die Todo-App verwenden, um Ihre Aufgaben zu organisieren.

## 🚀 Start

```bash
python main.py
```

## 📋 Grundfunktionen

### Aufgabe erstellen

1. Klicken Sie auf "Neue Aufgabe"
2. Geben Sie Titel ein
3. Fügen Sie eine Beschreibung hinzu (optional)
4. Wählen Sie Priorität (Niedrig/Normal/Hoch)
5. Setzen Sie ein Fälligkeitsdatum (optional)
6. Klicken Sie auf "Speichern"

### Aufgabe bearbeiten

1. Wählen Sie eine Aufgabe aus der Liste
2. Klicken Sie auf "Bearbeiten"
3. Ändern Sie die Felder
4. Klicken Sie auf "Speichern"

### Status ändern

- **In Arbeit setzen**: Rechtsklick → "In Arbeit"
- **Als erledigt markieren**: Rechtsklick → "Erledigt"
- **Wieder öffnen**: Rechtsklick → "Wieder öffnen"

### Filtern und Suchen

- **Status-Filter**: Dropdown oben links
- **Prioritäts-Filter**: Dropdown oben rechts
- **Textsuche**: Suchfeld für Titel/Beschreibung

## ⌨️ Tastenkombinationen

- `Ctrl+N` - Neue Aufgabe
- `Ctrl+E` - Bearbeiten
- `Ctrl+D` - Löschen
- `Ctrl+F` - Suche fokussieren
- `F5` - Liste aktualisieren

## 💡 Tipps

- Nutzen Sie Prioritäten für wichtige Tasks
- Filtern Sie nach "In Arbeit" für aktuelle Tasks
- Erledigte Tasks werden automatisch ausgegraut
