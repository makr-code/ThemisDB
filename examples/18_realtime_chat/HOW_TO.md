# Real-Time Chat - Anleitung

## 🚀 Schnellstart

```bash
cd examples/18_realtime_chat
pip install -r requirements.txt
python main.py
```

## 📖 Hauptfunktionen

### Chat Rooms
- Öffentliche Räume beitreten
- Private Räume erstellen
- Mitglieder einladen

### Direct Messages
- 1:1 Conversations
- Typing Indicators
- Read Receipts

### Message Features
- Text-Messages senden
- Dateien teilen (Bilder, Docs)
- Emoji-Reaktionen hinzufügen
- Messages bearbeiten/löschen

### Search
- Full-Text Suche über alle Messages
- Filter nach Datum, Sender, Room
