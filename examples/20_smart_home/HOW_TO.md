# Smart Home Dashboard - Anleitung

## 🚀 Schnellstart

```bash
cd examples/20_smart_home
pip install -r requirements.txt
python main.py
```

## 📖 Hauptfunktionen

### Device Management
- Alle Geräte in Übersicht
- Status anzeigen (Online/Offline)
- Geräte manuell steuern
- Gruppen erstellen (Räume)

### Automation Rules
- Neue Regel erstellen:
  1. Trigger definieren (Zeit, Sensor, Event)
  2. Bedingungen setzen
  3. Aktionen festlegen
  4. Regel aktivieren

### Scenes
- Vordefinierte Zustände:
  - "Good Morning"
  - "Movie Night"
  - "Away from Home"
- Mit einem Klick aktivieren

### Energy Monitoring
- Verbrauch pro Gerät
- Tages-/Monatsübersichten
- Kosten-Kalkulation
- Optimierungsvorschläge
