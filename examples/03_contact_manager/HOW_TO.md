# Kontaktmanager - Bedienungsanleitung

## 🎯 Übersicht

Verwalten Sie Ihre Kontakte effizient mit vollständiger Suche und Kategorisierung.

## 🚀 Start

```bash
python main.py
```

## 📋 Grundfunktionen

### Kontakt hinzufügen

1. Klicken Sie auf "Neuer Kontakt"
2. Füllen Sie die Pflichtfelder aus (Name, Email)
3. Fügen Sie optionale Informationen hinzu
4. Wählen Sie eine Kategorie
5. Klicken Sie auf "Speichern"

### Kontakt suchen

- **Schnellsuche**: Suchfeld oben
- **Kategorie-Filter**: Filter nach Freunde/Familie/Arbeit
- **Favoriten**: Zeige nur favorisierte Kontakte

### Kontakt bearbeiten

1. Wählen Sie einen Kontakt aus der Liste
2. Details werden rechts angezeigt
3. Klicken Sie auf "Bearbeiten"
4. Ändern Sie die Informationen
5. Speichern Sie die Änderungen

### Export/Import

**Export**:
- Datei → Export → JSON oder CSV wählen
- Speicherort auswählen

**Import**:
- Datei → Import → Datei auswählen
- Vorschau prüfen → Importieren

## ⌨️ Tastenkombinationen

- `Ctrl+N` - Neuer Kontakt
- `Ctrl+E` - Bearbeiten
- `Ctrl+D` - Löschen
- `Ctrl+F` - Suche
- `Ctrl+I` - Import
- `Ctrl+Shift+E` - Export

## 💡 Tipps

- Nutzen Sie Kategorien für bessere Organisation
- Markieren Sie wichtige Kontakte als Favoriten
- Volltext-Suche findet auch Teile von Namen
- Export regelmäßig für Backups

## 🔍 Suchbeispiele

- `max` - Findet "Max" in allen Feldern
- `@gmail.com` - Findet alle Gmail-Kontakte
- `Berlin` - Findet alle Kontakte aus Berlin
