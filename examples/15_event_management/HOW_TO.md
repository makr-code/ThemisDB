# Event Management - Anleitung

## 🚀 Schnellstart

```bash
cd examples/15_event_management
pip install -r requirements.txt
python main.py
```

## 📖 Hauptfunktionen

### Event erstellen
1. Klicken Sie auf "New Event"
2. Geben Sie Details ein (Titel, Datum, Ort)
3. Definieren Sie Ticket-Typen und Preise
4. Setzen Sie Kapazitätslimits
5. Speichern und veröffentlichen

### Teilnehmer-Registrierung
- Online-Anmeldung mit Ticket-Auswahl
- Automatische Bestätigungs-Emails
- QR-Code für Check-In

### Check-In Tracking
- QR-Code-Scanner für Check-In
- Live-Statistiken zu Anwesenheit
- Kapazitäts-Monitoring
