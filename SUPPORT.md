## 🐛 Bug Reports

If you've found a bug, please:

1. Check if the issue already exists in our [issue tracker](https://github.com/makr-code/ThemisDB/issues)
2. If not, [create a new issue](https://github.com/makr-code/ThemisDB/issues/new/choose)
3. Use the appropriate issue template
4. Provide as much detail as possible:
   - ThemisDB version
   - Operating system
   - Steps to reproduce
   - Expected vs. actual behavior
   - Relevant logs or error messages

## 💡 Feature Requests

Have an idea for a new feature? We'd love to hear it!

1. Check existing [feature requests](https://github.com/makr-code/ThemisDB/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement)
