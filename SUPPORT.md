## Where to Ask What

### Bugs

1. Check existing issues: <https://github.com/makr-code/ThemisDB/issues>
2. Open a new issue: <https://github.com/makr-code/ThemisDB/issues/new/choose>
3. Include version, OS, reproduction steps, expected vs. actual behavior, and relevant logs.

### Feature Requests

- Browse/open enhancements: <https://github.com/makr-code/ThemisDB/issues?q=is%3Aissue+is%3Aopen+label%3Aenhancement>

### Questions & Community

- GitHub Discussions: <https://github.com/makr-code/ThemisDB/discussions>

### Security

- Do **not** report vulnerabilities in public issues.
- Follow [SECURITY.md](SECURITY.md).
