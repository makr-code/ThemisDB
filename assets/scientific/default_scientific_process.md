## Zweck
Standardprozess für wissenschaftliche Fragestellungen mit reproduzierbarer Evidenzführung.

## Prozessbild
```mermaid
flowchart LR
  A[Question] --> B[Hypothesis]
  B --> C[Method]
  C --> D[Evidence]
  D --> E[Analysis]
  E --> F[Report]
```
